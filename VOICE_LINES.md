# DEAD AIR: voice line chart

Every spoken line in the game. Record each one as an **MP3** named exactly like the **File** column and put it in the `vo/` folder (for example `vo/dir_intro_1.mp3`). The game plays your recording automatically when the file exists, and uses the computer voice when it doesn't, so you can record a few at a time.

Tips: one take per file, a little silence trimmed off both ends, no music. The Director gets a radio/earpiece filter added by the game, so record him clean. Muffled bag lines should sound like someone yelling through plastic over their mouth.
